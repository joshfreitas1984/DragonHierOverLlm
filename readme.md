# Fateseeker English Patch

Install guide:

Install [BepinEx Bleeding Edge build for IL2CPP x64](https://builds.bepinex.dev/projects/bepinex_be). It was compiled with #785.
Extract the [Latest Release](https://github.com/joshfreitas1984/DragonHierOverLlm/releases) into your `<Game Folder>` folder where Fateseeker.exe is.
